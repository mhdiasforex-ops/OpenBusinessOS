**Versão:** 1.0

## Visão Geral

Mapeamento de precificação dos principais softwares concorrentes por nicho. Objetivo: posicionar o BusinessOS competitivamente e entender a disposição a pagar de MPEs brasileiras.

---

## Modelos de Precificação Observados

| Modelo | Descrição | Nichos |
|---|---|---|
| **SaaS por usuário** | R$ X/usuário/mês | ERPs horizontais (ContaAzul, Omie) |
| **SaaS por módulo** | R$ X/módulo/mês | ERPs modulares (TOTVS, SAP B1) |
| **SaaS flat** | R$ X/mês (tudo incluso) | Asaas, Nibo |
| **Per-transação** | % por NF-e emitida, R$ por boleto | Gateways fiscais (Focus NF-e) |
| **Freemium** | Free até X + pago acima | Nibo (MEI free), Bling (1 usuário free) |
| **On-premise + licença** | Licença única + mantença anual | MV Sistemas, Domínio (legado) |
| **Por volume de dados** | R$ X por N alunos/pacientes | Sponte, iClinic |

## Recomendação de Precificação para o BusinessOS

### Modelo Proposto: Freemium + Flat por Tier + Marketplace

| Tier | Preço | Inclui | Target |
|---|---|---|---|
| **Community** | Free | Financeiro básico + CRM básico + 1 usuário | MEI, autônomos |
| **Starter** | R$ 79/mês | Financeiro + Fiscal (NF-e) + CRM + 2 usuários | Microempresas |
| **Business** | R$ 199/mês | Todos módulos core + RH + 5 usuários | Pequenas empresas |
| **Professional** | R$ 399/mês | Business + módulos verticais + 10 usuários | MPEs em nicho |
| **Enterprise** | R$ 799/mês | Professional + API + multi-org + ilimitado | Médias empresas |

### Marketplace de Plugins
- Módulos verticais de subnicho: R$ 29-99/mês cada
- Integrações (gateways, SEFAZ, bancos): R$ 19-49/mês cada
- Templates e relatórios: R$ 9-29/mês cada

### Diferencial Competitivo
- **Community free** = aquisição (canal como Nibo/Asaas)
- **R$ 79 Starter** = 40-60% mais barato que ContaAzul/Omie entry
- **Módulos verticais ativáveis** = paga só pelo nicho que precisa
- **Open source** = auto-hospedagem para quem não quer SaaS
