# Módulo CRM

## Visão Geral
O módulo de CRM do BusinessOS é responsável por gerenciar o relacionamento com o cliente, incluindo:
- Funil de vendas
- Automação de marketing
- Integração com WhatsApp

## Funcionalidades

### Funil de Vendas
- Gestão de leads
- Etapas do funil (prospecção, abordagem, proposta, negociação, fechamento)
- Integração com sistemas de mensagens (WhatsApp, SMS, e-mail)

### Automação de Marketing
- Campanhas de follow-up automático
- Segmentação de clientes
- Integrações de dados
